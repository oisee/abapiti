## Correctness and CI

The normal workflow job **go target** uses setup-go's cache and a 15-minute
job timeout. It builds pinned Node abaplint `577f875e`, downloads the check kit
from the `oisee/abapiti` v0.1.1 release, generates and builds TS-HG@Go, runs the
lexer differential (44/44, with a token mutation rejected) and registry array,
sort, iterator, feature, typed JSON and tagged XML oracles. The script fails if
any required oracle is skipped. Finally it compares raw stdout with both kit
expected files, including the final newline, without normalization. No branch
protection settings or required-check declarations were changed.

The diagnostics regression executes JSON, XML, numeric, dynamic regex, dollar
replacement, pruned-body and ClassValue factory refusals through emitted Go and
requires their TS location. Refusals retain typed internal unwinding; the CLI
prints a diagnostic and exits nonzero without a Go panic traceback. A source map
is inspected only on failure, so successful checks need no per-method stack
capture. Static unsupported shapes still use frontend/HIR/emitter diagnostics.

## Measurements and gates

Go 1.26.0, Node 26.9.0, linux/amd64, four logical CPUs. Runs are sequential
under `flock /tmp/abapiti-heavy.lock`, with
`GOCACHE=$HOME/.cache/abapiti-go-cache`, `GOFLAGS=-buildvcs=false`, and default
GOGC/GOMAXPROCS. All temporary files and checkouts are in this clone or
`$HOME/.cache`. Other builds were active on this machine, so these wall times
are not directly comparable to the earlier 5.3-second observation.

| Operation | Seconds |
|---|---:|
| Generation (unpack + TS checker/lowering + HIR Go emission) | 20.394 |
| Go build (warm standard-library cache; generated package recompiled) | 25.6 |
| Generation + Go build | 46.0 |
| Clean check, median of 3 | 12.261 |
| Seeded check, median of 3 | 13.053 |

Check wall time includes process startup, file/dependency loading, checking and
stdout. Clean samples: 12.668, 11.825, 12.261 seconds. Seeded samples: 12.353,
15.750, 13.053 seconds. Every sample matched the release kit byte for byte.
The Go target verification phase (generation/build + 13.0-second oracles +
one clean/seeded kit pair) took approximately 85 seconds locally, excluding
Node checkout/npm preparation; the job's 15-minute timeout leaves headroom.
See [raw samples](2026-10-10-target-go.json).

Repository gates passed:

- `go vet ./...`
- `go test -short ./...`
- `./.github/ci/lint.sh gate origin/main`: zero new issues; canary 5/5;
  golangci-lint 2.13.2 from `~/.local/bin`.

The lint correction replaces an unchecked string-literal type assertion with
an explicit diagnostic. It preserves valid literal emission. Diagnostic source paths are normalized to
`src/`, `harness/` and `node_modules/`, following main’s ABAP source-map
convention without modifying the shared HIR. The four generated module files
are byte-identical across separate temporary checkouts. With an empty PATH,
the CLI writes those same buildable sources and leaves no executable. GitHub Actions
was not launched: the job's script was run locally with the pinned Node build
and downloaded release kit, and no PR was opened.
