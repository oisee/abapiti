# Delete record keys on train 11

Base: `b4cba6363f96073e870f0bfb45252397b085ad55` (`origin/integ/train-11`).
Implementation: `46e56fb7279b76bb77d3974bd338639c9f34448e`.
Original abaplint: `577f875ebec44cfaf64841cfe71c8ab8dc32622e`, locked TypeScript 6.0.3.
Only `root`, `lsp`, and `pretty_printer` are measured; no whole-suite result is claimed.

The new `dynamic.delete` HIR operation returns true after removing an own key.
Parsed dynamic objects delete directly from their ordered property storage. Live
config views retain their original source and delete through that source. Native
structural records and class instances delete optional or dynamic fields, clearing
the stored value while tracking property absence separately from an own property
whose value is undefined. Existing order metadata preserves the remaining keys;
a later assignment restores presence and appends the deleted key. Inherited
optional fields share that presence state. Optional-chain deletion of an absent
receiver returns true without accessing its storage.

Required native fields explicitly refuse deletion because their typed reads
cannot represent undefined. Other dynamic storage without a deletion adapter
also refuses. ABAP explicitly lists this new operation as unsupported pending a
corresponding property-presence ABI. The default zabapgit closure uses no new
operation. The existing Map-entry and sparse-array operations are unchanged.

`TestDeleteRecordsNodeOracle` compares the emitted Go with original Node for
live aliases, native and structural optional fields, repeated deletion, remaining
key order, reinsertion order, inherited fields, own-property absence, undefined
reads, optional chaining and a single receiver evaluation. It separately checks
the required-field refusal. The own-property observation uses the existing HIR
operation so this repair does not extend separately owned builtin lowering.

The Grace lexer golden changes only the new catalogue's effect-fact counts:
`op_aliases`, `op_allocates`, `op_may_raise`, and `op_writes` each gain one;
`op_reads` gains two. All 61 Grace call sites and oracle comparisons remain equal.
