## Answer and evidence convention

**Feasible as a staged engineering project; not available as an existing HIR capability.** Grace already separates rules, facts, indexed matching, and native actions. HIR can represent a deliberately rewritten relational kernel and its residual matchers. The missing bridge is substantial: an engine representation in HIR, a specialiser, a fact/API binding, a small TS backend, and safe edit semantics. The full single-use CAST rule is **not shape-only**.

Evidence labels used throughout:

- **Verified** means inspected in the pinned code, or executed in the checks recorded below. Source-linked statements describing existing behavior are verified code observations unless explicitly qualified.
- **Assumption / proposed** means an unimplemented design, an inference about feasibility, an estimate, a semantic property not established by these checks, or future acceptance/performance. All code in “by-hand residual” sections is proposed, not generated by an existing compiler.
- **Theory** means a definition supported by the cited primary technical source, not a repository capability. A successful specialisation would still need validation; the equations do not establish an implementation's correctness.
- Historical documentation is identified as such; its performance numbers were **not remeasured** here. Negative implementation findings are bounded to the production paths and searches described below.

### Which projection is actually meant?

**Theory.** Let `E(R, F)` evaluate Grace rules `R` on facts `F`, and let `S(P, s)` specialise program `P` on its static input `s`. Then:

```text
P1: M_R = S(E, R)                 M_R(F) = E(R, F)
P2: C_E = S(S, E)                C_E(R) = S(E, R)
P3: G   = S(S, S)                G(E')  = S(S, E')
```

These are the definitions given by [Neil D. Jones, Binding Times, Optimal Specialisation and Types, slides 5 and 12–13](https://www.nii.ac.jp/userimg/lectures/neiljones/TokyoSlidesOptimality-2.pdf). P2 requires a self-applicable specialiser, not just a Go function that accepts a rule and emits HIR. P3 specialises the specialiser to itself; running P1 on a second engine is reuse, not P3. A compiler generator `G` could subsequently accept an interpreter for GIR rules.

**Assumption / proposed.** Separate three achievable products: (a) a direct Grace→HIR rule compiler, (b) P1 using a HIR engine, (c) self-application for P2/P3. Product (a) can deliver useful vanilla abaplint rules without demonstrating any projection. Product (b) can demonstrate P1 without P2. Do not make the useful product depend on self-application research.

Verified: `hir/rewrite` aliases the Go Grace core and delegates parsing/evaluation; it does not hold the engine as HIR: [hir/rewrite/core.go:4](https://github.com/oisee/abapiti/blob/b5a191bc07682054dc822427d6b157c31cd737fd/hir/rewrite/core.go#L4). `Analyze` extracts HIR facts, parses embedded Grace, and invokes that Go evaluator: [hir/rewrite/analyze.go:14](https://github.com/oisee/abapiti/blob/b5a191bc07682054dc822427d6b157c31cd737fd/hir/rewrite/analyze.go#L14). ### Proposed binding-time analysis: rule static, AST dynamic

**Assumption / proposed.** BTA needs at least `S` (known static value), `D` (runtime value) and **partially static records/arrays**. The important mixed object is a relation descriptor whose predicate/arity/index columns are static but whose rows are dynamic.

| Value/control | Binding time | Treatment |
|---|---|---|
| Parsed rule clauses, constants, term tags, names, priorities, arities, bound annotations | S | Validate once, eliminate parser and dispatch on these values. |
| Goals, dependency graph, strata, relation recursion SCCs | S | Precompute schema/schedule. Preserve semantic priority and deterministic output contract. |
| Variable→slot map; equality tests between repeated variables; which columns become bound after each atom | S | Replace environment dictionaries/undo interpretation with named residual locals and fixed tests. |
| Relation name and chosen index mask | S; table contents D | Resolve a concrete accessor at compile time; residual lookup receives dynamic keys. |
| Cardinality used by `planJoin` | D in general | Choose a fixed documented order from static schema, or residualise plan selection. The current heuristic reads runtime row counts; do not stage those by accident. |
| Symbol interner | Mixed | Static literal string is S; its numeric ID is D if interning shares a mutable runtime symbol table. Freeze a static symbol prefix or emit direct literal comparisons. |
| Rule `(fact ...)` declarations | S input facts | Stage only static-only derivations. AST-derived rows and any relation depending on them remain D even if the relation name is known. |
| AST handles, child arrays, token text, source spans, semantic references, release/config | D | Generate adapter reads/guards; release/config can be S only for a deliberately version-bound artifact. |
| Candidate join bindings and join success | D | Residual loops/branches. Known atom sequence can be unfolded without evaluating dynamic fact contents. |
| `pos` in join interpreter | S for finite nonrecursive atom list | Unroll atom-dispatch recursion to nested loops; remaining AST traversal may remain residual. |
| Delta tables, fresh-fact checks, fixpoint `changed` | D | Recursive relation SCCs become specialised runtime worklists/semi-naive loops. Do not unroll to a guessed number of rounds. |

**Assumption / proposed PE algorithm.** (1) Freeze a validated rule/schema and annotate kernel HIR; (2) evaluate pure static expressions and immutable heap reads; (3) specialise calls by static arguments and binding pattern; (4) create residual HIR expressions/statements for dynamic operations; (5) lift static constants into residual literals; (6) fold static branches/remove dead dispatch; (7) verify HIR and required runtime ops; (8) pass to emitters. **Assumption / proposed memo/termination policy.** Key residual versions by `(method/site, canonical static arguments, binding pattern, static heap snapshot/version)`. Memoise before descending; reuse a residual call on recurrence. Limit static steps, specialisation depth, variants per method, and total residual nodes. Known finite rule lists are safe to unfold structurally; unknown AST loops are residual. **Assumption:** a Go specialiser can provide P1 first. ### Grace rule (current parser syntax; proposed fact contract)

The following text was parsed and evaluated with the **existing** Grace engine. Its relations are proposed abaplint facts, not an implemented extractor. It deliberately uses ordinary `(rule ...)` to produce an action relation; no unsupported Grace action syntax is claimed.

```grace
(rule extra-access 10
 (head (extra_access ?b ?d ?u))
 (base (cast_bind ?m ?s ?b ?d ?payload)
       (read ?b ?u ?n)
       (access ?b ?p ?mode) (neq ?p ?d) (neq ?p ?u)))

(rule single-use-cast 0
 (head (inline_cast ?s ?u ?payload))
 (base (cast_bind ?m ?s ?b ?d ?payload)
       (next_in_block ?s ?n)
       (read ?b ?u ?n) (read_only ?b ?u)
       (local_binding ?m ?b) (complete_scope ?m) (closed_binding ?m ?b)
       (safe_eval ?s ?n ?u) (legal_inline ?s ?n ?u ?payload)
       (not (extra_access ?b ?d ?u))))
```

All terms are positively bound before negation; `neq` is a built-in comparison ([grace/engine.go:192](https://github.com/oisee/abapiti/blob/b5a191bc07682054dc822427d6b157c31cd737fd/grace/engine.go#L192)). `extra_access` is completed in the lower stratum before its negative guard ([grace/engine.go:52](https://github.com/oisee/abapiti/blob/b5a191bc07682054dc822427d6b157c31cd737fd/grace/engine.go#L52)). No count aggregate is needed: retain every occurrence, and forbid any access other than the definition and chosen read. `read_only` rejects a write/aliasing mode at the same occurrence ID, which the `neq` exclusions alone would miss. Synthetic tests returned one result for the valid case and zero for second read, second write, missing `closed_binding`, or missing `safe_eval`.

**Assumption / proposed relation definitions:**

| Fact | Meaning and source needed |
|---|---|
| `cast_bind(method, stmt, binding, definitionOccurrence, payload)` | Exact permitted assignment/CAST shape plus resolved binding. Payload identifies original CAST span/text, or a type-checked explicit CAST reconstruction for a later `?=` extension. |
| `next_in_block(stmt,next)` | Direct lexical execution adjacency, not adjacency in the whole file's flat statement array. |
| `read(binding, occurrence, stmt)` | Every resolved read in the complete owning method, including before the definition in loops and in handlers. |
| `access(binding, occurrence, mode)` | All reads/writes/other statically attributable accesses; defining write included. Unknown access possibilities prevent `closed_binding`. |
| `read_only(binding, occurrence)` | Ordinary value read, not a writable argument, reference-taking or other alias-producing use. |
| `local_binding(method,binding)` / `complete_scope(method)` | Helper is local; syntax analysis and the relevant scope closure are complete and clean. |
| `closed_binding(method,binding)` | No unaccounted alias/dynamic/macro access; no uncertainty about reference accounting. Must be positive evidence, not inferred from missing hazard facts. |

| `legal_inline(stmt,next,occurrence,payload)` | Replacement grammatical/type context, release and origin are valid; simple/explicit type as required; no chained declaration, protected comments/pragmas or unresolved lifetime issue. |
| `inline_cast(stmt,occurrence,payload)` | Runtime action record: replace this read and remove the helper statement; one snapshot, nonoverlapping edits. |

The last safety relations encapsulate real work. **Assumption:** there is no existing universal abaplint `safe_eval` or `closed_binding` API. ### By hand: what P1 should leave in HIR

  static run(f: CastFacts) -> Array<Match>:

    foreach c in f.castBindings:                         # runtime rows
      if not f.localBinding(c.method, c.binding): continue
      if not f.completeScope(c.method): continue

          if not f.readOnly(c.binding, u.occurrence): continue
          if not f.safeEval(c.statement, n, u.occurrence): continue
          if not f.legalInline(c.statement, n, u.occurrence, c.payload): continue
          var extra = false
          foreach a in f.accessesByBinding(c.binding):
            if a.occurrence != c.definition and a.occurrence != u.occurrence:
              extra = true; break
          if not extra:
            out.push(new Match(c.statement, u.occurrence, c.payload))
    return out
```

### By hand: resulting vanilla TS IRule

**Assumption / proposed TS sketch.** Imports below are the verified internal core paths. `CastFacts`/`buildCastFacts` are **new proposed adapter types/functions**, not pinned APIs. ```ts
import {IRule, IRuleMetadata, RuleTag} from "./_irule";
import {BasicRuleConfig} from "./_basic_rule_config";
import {IObject} from "../objects/_iobject";
import {ABAPObject} from "../objects/_abap_object";
import {IRegistry} from "../_iregistry";
import {Issue} from "../issue";
import {SyntaxLogic} from "../abap/5_syntax/syntax";
import {EditHelper} from "../edit_helper";
import {Release, releaseAtLeast} from "../version";
import {buildCastFacts} from "../grace_adapter/cast_facts"; // proposed

class SingleUseCastConf extends BasicRuleConfig {}

export class SingleUseCast implements IRule {
  private reg!: IRegistry;
  private conf = new SingleUseCastConf();

  public getMetadata(): IRuleMetadata {
    return {key: "single_use_cast", title: "Inline single-use CAST",
      shortDescription: "Inline a safely movable single-use CAST helper.",
      tags: [RuleTag.Experimental, RuleTag.Quickfix]};
  }
  public getConfig() { return this.conf; }
  public setConfig(conf: SingleUseCastConf): void { this.conf = conf; }
  public initialize(reg: IRegistry): IRule { this.reg = reg; return this; }

  public run(obj: IObject): readonly Issue[] {
    if (!(obj instanceof ABAPObject)) { return []; }
    if (!releaseAtLeast(this.reg.getConfig().getRelease(), Release.v740sp02)
        && !this.reg.getConfig().isOpenABAP()) { return []; }
    const syntax = new SyntaxLogic(this.reg, obj).run();
    if (syntax.issues.length > 0) { return []; }
    const issues: Issue[] = [];
    for (const file of obj.getABAPFiles()) {
      // Builds complete method facts before any negative lookup; does not edit.
      const f = buildCastFacts(this.reg, obj, file, syntax);
      const emitted = new Set<string>();
      for (const c of f.castBindings) {
        if (!f.localBinding(c.method, c.binding)
            || !f.completeScope(c.method)
            || !f.closedBinding(c.method, c.binding)) { continue; }
        for (const n of f.nextByStatement(c.statement)) {
          for (const u of f.readsByBinding(c.binding)) {
            if (u.statement !== n || !f.readOnly(c.binding, u.occurrence)
                || !f.safeEval(c.statement, n, u.occurrence)
                || !f.legalInline(c.statement, n, u.occurrence, c.payload)) {
              continue;
            }
            let extra = false;
            for (const a of f.accessesByBinding(c.binding)) {
              if (a.occurrence !== c.definition && a.occurrence !== u.occurrence) {
                extra = true; break;
              }
            }
            if (extra) { continue; }
            const key = f.matchKey(c.statement, u.occurrence, c.payload);
            if (emitted.has(key)) { continue; }
            emitted.add(key);
            // Adapter maps occurrence IDs back to verified AST handles/text.
            const statement = f.statementNode(c.statement);
            const token = f.readToken(u.occurrence);
            const text = f.payloadText(c.payload);
            const fix = EditHelper.merge(
              EditHelper.replaceToken(file, token, text),
              EditHelper.deleteStatement(file, statement));
            issues.push(Issue.atStatement(file, statement,
              "Inline single-use CAST helper", this.getMetadata().key,
              this.conf.severity, fix));
          }
        }
      }
    }
    return issues;
  }
}
```

2. Change dynamic CAST token/type/child order and its output changes without re-specialising. Change the static rule, re-specialise, and output changes accordingly. Include a non-CAST negative fixture.
